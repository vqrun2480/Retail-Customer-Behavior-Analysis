# 🛍️ Retail Customer Behaviour Analysis

## Overview

This project analyses retail customer purchasing behaviour using a complete data analytics workflow. It involves data loading, cleaning, exploratory data analysis (EDA), SQL-based business analysis, and interactive dashboard creation to uncover valuable business insights.

The project demonstrates practical skills in data analysis and visualisation using industry-standard tools commonly used by Data Analysts.

---

## Dataset

The dataset contains retail transaction data, including customer information, product details, purchase amounts, discounts, payment methods, and shopping behaviour.

Key attributes include:

* Customer demographics
* Product categories
* Purchase amount
* Discount information
* Payment method
* Shopping frequency
* Customer ratings

---

## Tools & Technologies

* **Python** – Data loading, cleaning, and analysis
* **Jupyter Notebook** – Exploratory Data Analysis (EDA)
* **Pandas** – Data manipulation and preprocessing
* **Matplotlib & Seaborn** – Data visualisation
* **PostgreSQL** – SQL queries and business analysis
* **Power BI** – Interactive dashboard and reporting

---

## Project Workflow

1. Loaded the dataset into Python.
2. Performed data cleaning and preprocessing.
3. Conducted Exploratory Data Analysis (EDA) to identify trends and patterns.
4. Imported the cleaned data into PostgreSQL.
5. Executed SQL queries to answer key business questions.
6. Built an interactive Power BI dashboard to present insights visually.

---

## Dashboard

The Power BI dashboard provides an overview of key business metrics, including:

* Total Sales
* Customer Distribution
* Revenue by Product Category
* Purchase Trends
* Discount Analysis
* Customer Behaviour Insights
* Interactive filters and slicers for detailed exploration

---

## Results

The analysis revealed valuable insights into customer purchasing behaviour, product performance, and sales trends. These findings can support business decisions related to marketing, inventory management, customer segmentation, and overall retail strategy.

---

## How to Run

1. Clone this repository.
2. Open the Jupyter Notebook and install the required Python libraries.
3. Run the notebook to perform data cleaning and EDA.
4. Import the dataset into PostgreSQL and execute the SQL scripts.
5. Open the Power BI (.pbix) file to explore the interactive dashboard.
